# Fase 137 — Señal de confianza del modelo

Fecha de revisión: 2026-08-11
Versión: 0.191.0

## Objetivo

Dar contexto visible sobre la calidad declarada de una escena sin crear una falsa sensación de certificación o monitoreo en vivo.

## Implementado

- Badge compacto bajo demanda en el canvas.
- Etiquetas diferenciadas para cobertura base, fuentes específicas y modelo revisado.
- En técnico: estado, reglas comprobadas, hallazgos y número de fuentes declaradas.
- En cliente: lenguaje de representación conceptual, sin saturar la primera lectura.
- Límite explícito: las comprobaciones validan el modelo autorado, no la red real.

## Verificación

Typecheck, lint, build y consistencia de versión.
