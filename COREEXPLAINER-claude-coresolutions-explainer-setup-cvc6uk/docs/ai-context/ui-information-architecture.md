# Contexto IA — Arquitectura de información

La Fase 1 define tres superficies del dashboard:

- **Explorar:** temas para presentar.
- **Revisar:** fuentes, cobertura, escenarios y preparación técnica.
- **Crear:** borradores de nuevas explicaciones.

Al modificar el dashboard, no mezclar estas superficies de nuevo. Explorar debe
ser la vista inicial; Revisar y Crear deben permanecer progresivos y claramente
etiquetados. No eliminar una herramienta existente sólo para reducir ruido:
muévela a la superficie que corresponda y conserva su acceso.
