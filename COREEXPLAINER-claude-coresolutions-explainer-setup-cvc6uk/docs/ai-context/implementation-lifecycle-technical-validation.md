## Alcance

El contenido es un patrón de delivery derivado de proyectos sanitizados de
CORESOLUTIONS. No define una metodología contractual, un SLA ni una lista
cerrada de tareas. Cada proyecto debe convertirlo en un plan con responsables,
dependencias, ventanas, pruebas y aceptación.

## Límites

- El patrón no reemplaza site survey, HCL, sizing, licenciamiento ni runbook.
- Las pruebas deben acordarse con el cliente y cubrir cada dependencia del
  servicio.
- La documentación y la transferencia de conocimiento forman parte del cierre
  operativo, pero no prueban por sí solas una capacidad técnica.
