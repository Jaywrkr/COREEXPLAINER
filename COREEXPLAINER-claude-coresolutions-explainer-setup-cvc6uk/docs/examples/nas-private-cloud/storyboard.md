# Storyboard — NAS como servicio de archivos

**Revisión:** 2026-08-04  
**Marcas:** Synology, Aruba HPE, Check Point, Veeam y Lenovo.

Este tema representa los proyectos de NAS, file server, Active Directory,
enlaces agregados, alta disponibilidad y migración de archivos observados en
la planificación.

1. Servicio: shares, protocolos, capacidad y red.
2. Identidad: AD, DNS, NTP, grupos y ACL.
3. HA: activo, pasivo, heartbeat e IP de cluster.
4. Protección: RAID, HA, Veeam y restore.
5. Límites: directorio, enlace HA, permisos y backup.

RAID, HA y backup se explican como controles diferentes. El modelo no promete
que cualquier NAS sea una nube privada, ni que HA proteja contra borrado,
ransomware o errores lógicos.
