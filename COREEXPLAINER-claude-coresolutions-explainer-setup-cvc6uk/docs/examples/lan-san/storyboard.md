# Storyboard — LAN y SAN integradas

**Revisión:** 2026-08-04  
**Marcas:** Aruba HPE, IBM, Lenovo, VMware/Broadcom y Check Point.

Este tema explica por qué una plataforma de data center tiene varios planos de
tráfico y cómo se integran sin dibujarlos como una sola red.

1. Planos: gestión, usuarios, VMs, vMotion, SAN y replicación.
2. LAN: switching, VLAN, routing, LAG y firewall.
3. SAN: HBA/WWPN, fabric, zoning y host mapping.
4. Integración: aplicación, dependencias, seguridad y storage.
5. Límites: VLAN, MTU, zoning y rutas.

La LAN Ethernet y la SAN FC pueden tener diseños independientes. El modelo no
afirma que un switch LAN transporte Fibre Channel ni que una política de
firewall corrija una configuración de storage.
