# Storyboard — IBM Turbonomic

**Revisión:** 2026-08-05
**Estado:** patrón conceptual pendiente de revisión especialista.

## Intención

Explicar cómo Turbonomic conecta aplicaciones, recursos y acciones mediante una
supply chain. El ejemplo diferencia recomendación, ejecución manual,
automatización y planes what-if para que el cliente no confunda optimización con
automatización sin control.

## Escenas

1. **Demanda:** la aplicación necesita recursos.
2. **Supply chain:** targets descubren entidades y relaciones.
3. **Mercado:** el motor equilibra demanda, oferta y restricciones.
4. **Automatización:** política, workflow, aprobación y ejecución.
5. **Planes y límites:** simulación y supuestos abiertos.

## Marcas

IBM Turbonomic es el producto central; VMware/Broadcom, Lenovo e IBM Instana
representan targets y señales posibles. El soporte concreto depende de release,
target, permisos y política.
