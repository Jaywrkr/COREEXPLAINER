# Storyboard — IBM webMethods

**Revisión:** 2026-08-05
**Estado:** patrón conceptual pendiente de revisión especialista.

## Intención

Explicar la integración híbrida desde el paisaje de sistemas hasta el mensaje,
el runtime, el API Gateway y la operación. El ejemplo evita presentar una
integración como conectores sin gobierno ni soporte de versiones.

## Escenas

1. **Paisaje:** APIs, aplicaciones, eventos, B2B y archivos.
2. **Flujo:** mapping, servicio, backend y respuesta.
3. **Híbrido:** control plane, runtimes cloud y remotos.
4. **Gobierno:** gateway, identidad, portal y políticas.
5. **Límites:** runtime, API policy, mapping e interoperabilidad.

## Marcas

IBM webMethods es el producto central; VMware/Broadcom, Aruba HPE y Check Point
representan aplicaciones, conectividad y seguridad posibles. La matriz de
versiones y el patrón de despliegue se deben confirmar por proyecto.
