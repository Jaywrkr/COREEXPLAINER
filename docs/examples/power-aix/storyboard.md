# Storyboard — IBM Power/AIX para Oracle o SAP

**Revisión:** 2026-08-05
**Estado:** patrón conceptual pendiente de revisión especialista.

## Intención

Explicar la cadena completa de una carga crítica: aplicación, AIX, PowerVM,
VIOS, SAN, LAN, backup y aceptación. Live Partition Mobility se presenta como
una capacidad condicionada, no como sustituto de backup, replicación o pruebas
de aplicación.

## Escenas

1. **La carga:** dependencias de Oracle/SAP.
2. **Plataforma:** PowerVM, HMC, VIOS y destino.
3. **Datos y red:** paths, SAN, storage y usuarios.
4. **Aceptación:** aplicación, backup y evidencia.
5. **Límites:** prerrequisitos, paths, aplicación y restore.

## Marcas

IBM es la marca central; Lenovo, Veeam y Aruba HPE representan componentes de
integración. El alcance de cada modelo, release y licencia debe confirmarse.
