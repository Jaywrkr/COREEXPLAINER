# Fase 8 — Escenarios guiados

Los escenarios muestran una ruta causal consistente: **observa**, **diagnostica**,
**recupera** y **valida**. El estado minimizado conserva el nombre y el progreso;
al expandir, la ruta permite saltar a una fase concreta sin perder el contexto.

La simulación sigue siendo conceptual y no ejecuta cambios en la infraestructura.
