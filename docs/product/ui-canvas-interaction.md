# Fase 5 — Navegación profesional del canvas

El diagrama mantiene pan, zoom, selección y navegación por teclado, y añade una
acción explícita **Ajustar** para encuadrar todos los nodos de la escena. La
acción **Restablecer** conserva la vista base. El atajo `A` ajusta la escena, `0`
restablece y `+`/`−` cambian el zoom.

**Rama:** `codex/ui-canvas-interaction`
