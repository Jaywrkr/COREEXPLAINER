# Fase 1 — Arquitectura de información

La aplicación separa el dashboard por intención:

1. **Explorar:** temas para presentar.
2. **Revisar:** fuentes, cobertura, escenarios y preparación técnica.
3. **Crear:** borradores de nuevas explicaciones.

Explorar es la superficie inicial. Revisar y Crear permanecen disponibles, pero
se revelan bajo demanda para no competir con la selección de temas. No se elimina
ninguna capacidad técnica; se agrupa en el lugar donde el usuario espera hallarla.
