# Tutorial de Architecture Studio

> **Sincronizado:** 28-08-2026 contra `main` (`fc1c008`).

Architecture Studio es independiente de los temas explicativos. Sirve para discovery, preventa y handoff técnico.

1. Describe qué tiene el cliente, qué necesita y las restricciones conocidas.
2. Genera un borrador: la IA solo puede usar bloques, puertos y conexiones
   autorizados por el catálogo CORESOLUTIONS.
3. Revisa los supuestos, riesgos y pendientes que el Studio deja visibles.
4. Abre pantalla completa para organizar el canvas; usa zoom, centrado,
   filtros por capa y dominios (Sede, Data Center, Nube o DR Site).
5. Reubica equipos o ajusta el recorrido visual de los cables. La aplicación
   conserva la validación de extremos y protocolos; no permite convertir un
   ajuste visual en una conexión técnicamente inválida.
6. Completa producto, versión, modelo/sitio y fuente/HCL por marca antes de
   preparar la revisión de ingeniería.

Un estado conceptual completo no es aprobación: la implementación requiere validación humana, compatibilidad, sizing, seguridad, pruebas y aceptación.
