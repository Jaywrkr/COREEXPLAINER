# Veeam technical authority rules

## Scope

This rule pack applies source-to-scene controls to Veeam Protection and Backup/DR. It binds workload coverage, backup data movers, repositories, immutability, tape, restore and recovery claims to the Veeam documentation cited by the affected scene.

## Boundary

The rules prevent a conceptual diagram from turning a product capability into a customer guarantee. Exact workload support, plugins, agents, repository type, licences, configuration, RPO/RTO and restore evidence still require a reviewed customer design.
