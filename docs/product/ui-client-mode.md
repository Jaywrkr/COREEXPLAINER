# Fase 3 — Modo cliente limpio

El modo cliente prioriza significado y causalidad. Un badge técnico saludable
no ocupa espacio persistente, mientras que alertas de integridad o fuentes
pendientes siguen visibles. Las herramientas técnicas continúan accesibles bajo
demanda y el modo técnico conserva toda la información.

**Rama:** `codex/ui-client-mode`
