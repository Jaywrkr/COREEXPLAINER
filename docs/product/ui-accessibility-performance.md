# Fase 10 — Accesibilidad y fallback del canvas

El canvas visual incluye una alternativa semántica para lectores de pantalla:
componentes, relaciones y atajos se exponen como texto estructurado. La escena
sigue siendo interactiva con teclado y no depende únicamente de la interpretación
visual del diagrama.
