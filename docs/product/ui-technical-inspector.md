# Fase 4 — Inspector técnico unificado

El canvas ofrece una única entrada **Inspeccionar**. Dentro se puede cambiar
entre tres superficies, con sólo una abierta a la vez:

- **Integridad:** reglas, advertencias y evidencia del modelo.
- **Capas:** leyenda, nodos y relaciones visibles.
- **Escenarios:** fallos guiados y decisiones asociadas.

Esto conserva las capacidades existentes sin apilar paneles que compitan por el
mismo espacio. El inspector se puede cerrar y el diagrama vuelve a quedar limpio.

**Rama:** `codex/ui-technical-inspector`
