# Check Point technical authority rules

This pack binds Check Point ClusterXL traffic path, member compatibility, High Availability mode, synchronization and failover scenes to official Check Point sources. It specifically prevents describing active/standby HA as load sharing, or interpreting a cluster status as proof of application continuity.

The gate does not inspect policies, blades, Gaia release, interfaces, routes, NAT or session behavior. Those remain reviewed implementation evidence.
