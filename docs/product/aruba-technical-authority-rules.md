# HPE Aruba Networking technical authority rules

## Scope

This pack links HPE Aruba Networking sources to the LAN/SAN and SD-WAN scenes. It makes separate the traffic planes, Ethernet design, SD-WAN underlay, business intent, path conditioning and security boundary.

## Boundary

It does not validate a switch model, firmware, transceiver, circuit SLA, routing table, BIO, licence or live path. Those are customer-specific design and test artefacts and require review before any operational statement is published.
