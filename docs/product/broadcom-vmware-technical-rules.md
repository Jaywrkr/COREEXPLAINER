# Broadcom / VMware technical authority rules

This rule pack governs VCF, vSphere HA, vSAN, NSX and migration explainers. It requires the scene that makes a claim to cite the official evidence for release scope, HA capacity, storage availability, underlay/overlay dependency, firewall scope, routing path or migration prerequisites.

It does not approve any customer configuration. HCL, firmware, licenses, edition, hardware model, target release, vCenter/ESXi/vSAN/NSX combination, design and acceptance tests remain mandatory review inputs.
