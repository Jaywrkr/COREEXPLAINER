# Contexto IA — Quality gate UX/UI

Todo PR que modifique UI debe revisar la checklist UX/UI del template y la
puerta [`docs/audits/ui-release-quality-gate.md`](../audits/ui-release-quality-gate.md).
No aprobar cambios que oculten límites técnicos, rompan teclado o añadan
complejidad sin una tarea demostrable.
