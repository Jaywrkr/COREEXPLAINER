# UI simplification context

> **Sincronizado:** 28-08-2026.

The explainer follows progressive disclosure. Client mode exposes the active explanation and diagram first. Technical evidence, inspectors, scenarios, presentation controls and viewport controls remain available without competing with the narrative.

Keep the dashboard catalog visual and focused on topic discovery. Apply the
strongest progressive disclosure inside individual explainers: client mode
exposes only one active explanation and diagram, while technical controls
require the explicit **Detalle técnico** action.

The shared shell is deliberately two-level: Cliente and Detalle técnico. Do
not reintroduce a third audience selector unless it demonstrates a decision
that cannot be served by either level. Timeline, scene caption and operational
tools are technical-only; this prevents the canvas from competing with its
own controls.

Do not reintroduce a floating scene summary over the diagram. Its title,
caption and paragraph duplicate the left narrative while reducing the area
available to understand the topology. Keep optional operational workspaces out
of the explainer reading path unless a user explicitly enters a dedicated
workflow.
