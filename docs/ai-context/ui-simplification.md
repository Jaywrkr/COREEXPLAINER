# UI simplification context

The explainer follows progressive disclosure. Client mode should expose the current explanation and canvas first. Technical evidence, inspectors, scenarios, presentation controls, and viewport controls must remain available without competing with the primary narrative.

The `/explainer` dashboard is the entry point for presentation work. It must prioritize topic discovery and a single primary action (open a route). Internal operations are intentionally placed behind a closed disclosure region and must not add visual competition to the catalog.
