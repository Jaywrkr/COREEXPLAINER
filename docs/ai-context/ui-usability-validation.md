# Contexto IA — Validación UX

Antes de añadir una capacidad que afecte el flujo principal, usar el protocolo
[`docs/audits/ui-usability-validation-protocol.md`](../audits/ui-usability-validation-protocol.md).
Evaluar tareas por perfil, registrar primer clic y errores, y priorizar
comprensión, accesibilidad y confianza técnica antes que preferencias estéticas.
