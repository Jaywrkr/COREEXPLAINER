# Contexto IA — Modo cliente

> **Sincronizado:** 28-08-2026.

En modo Cliente, la primera lectura contiene solo una idea, un impacto y el
diagrama. No exponer metadata técnica saludable, guía de lectura, timeline,
caption técnico, puertos, leyendas, fuentes, marcas ni herramientas.

Las alertas críticas siguen disponibles por la ruta **Detalle técnico → Riesgos
y validación**; no deben competir con la narración cuando no están activas.
El modo `conceptual` deja de ser una elección visible: enlaces históricos se
normalizan a Cliente para evitar tres niveles de profundidad ambiguos.
